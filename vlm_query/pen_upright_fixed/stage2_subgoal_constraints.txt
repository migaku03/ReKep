def stage2_subgoal_constraint1(end_effector, keypoints):
    """Ensure the white pen is upright by aligning the vector from keypoint 0 to keypoint 1 with the z-axis."""
    pen_vector = keypoints[1] - keypoints[0]
    z_axis = np.array([0, 0, 1])
    # HAND-CORRECTED. Upstream was just the norm(cross(...)) below, which cannot tell up from
    # down: cross(v, z) is (vy, -vx, 0), so the cost is sqrt(vx**2 + vy**2) and the sign of vz
    # never enters. A pen held point-down scores exactly what a correct one scores -- which the
    # docstring plainly did not intend, since it says "aligning ... with the z-axis".
    #
    # Measured at the end of stage 3: the run that worked had vz = +0.150; the run that failed
    # had vz = -0.144 at a cost of 0.043, well inside constraint_tolerance 0.10, and the gripper
    # opened over a pen standing on its head. It fell: the outcome check read a 3.06 cm z span
    # against a 24.24 cm pen.
    #
    # The expression below is |v|*sin(theta) folded into |v|*(2 - sin(theta)) past horizontal,
    # theta being the angle from +z. That makes it MONOTONIC in theta -- 0 upright, |v| at
    # horizontal, 2|v| inverted -- and continuous at theta = 90 deg, where both branches give
    # |v|. Below horizontal it is identical to upstream, so solutions that already worked are
    # unaffected bit for bit.
    #
    # The first attempt at this fix added `2.0 * max(0, -v[2])` to the upstream term instead.
    # It scored inverted at 2|v| and upright at 0, which looked right on the two recorded runs,
    # but it left horizontal at only |v| -- so inverted became MORE expensive than lying flat,
    # and the solver duly went flat. Measured: |vz| collapsed to 0.019-0.063 on a 0.14 m span,
    # a pen held almost horizontal, with OSC failures up from 0 to 34. Checking a fix against
    # the two states you already observed is not enough; the ordering of everything in between
    # is what the optimizer actually searches over.
    horizontal = np.linalg.norm(np.cross(pen_vector, z_axis))
    if pen_vector[2] >= 0:
        cost = horizontal
    else:
        cost = 2.0 * np.linalg.norm(pen_vector) - horizontal
    return cost
